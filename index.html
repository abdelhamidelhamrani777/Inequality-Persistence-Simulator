Profile presets

A preset sets the allocation (the more persistent source receives the pattern the profile needs) and resets each person's parameters so that each income fluctuates around its own start: β=(1−φ)×start, trend 0, σ=start/10. With equal caps, the five presets keep every person’s period-0 income, hence the Lorenz curve and the Gini coefficient; only the split between labor and capital differs.

Notes

About the model

The persistence of an income share reflects the mix of income sources behind it

1.Timing

Period 0 is the allocation, wi,0 and fi,0. The recursion runs for t=1, …, T. r_Labor_Persist.m starts its index at 1, so its trend term is shifted by one period.

2.Parameters

Each person has their own β, trend and σ for each source. φL and φK are shared unless set by person.

3.Measuring persistence

ρ(1) is the first-order sample autocorrelation of each share, computed on its fluctuations around the no-shock path and averaged over the simulated samples. Whiskers show the 5th–95th percentiles across samples.

4.Theory line

A first-order linearization of each share around the long-run levels, for fixed individuals. It requires |φ|<1 for both sources and every trend at zero.

5.Units

Rank slots re-sort people by total income every period; a slot is then a position in the distribution rather than a person.

6.Random numbers

A Mulberry32 generator with Box–Muller normals; each person, source and sample has its own stream, so parameter changes reuse the same shocks.
